# সংজ্ঞা
২৷ এই আইনে “তদন্ত্ম নিষ্পন্ন” বলিতে সন্ত্রাসমূলক অপরাধ দমন আইন, ১৯৯২ (১৯৯২ সনের ৪৪ নং আইন), অতঃপর উক্ত আইন বলিয়া উলিস্্নখিত, এর বিধান অনুযায়ী কোন অপরাধ সম্পর্কে তদন্ত্ম শেষে Code of Criminal Procedure, 1898 (Act V of 1898), অতঃপর উক্ত Code বলিয়া উলিস্্নখিত, এর Section 173 এর অধীনে পুলিশ রিপোর্ট দাখিল করাকে বুঝাইবে৷
