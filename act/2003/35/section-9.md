# The Code of Criminal Procedure, 1898 এবং the Code of Civil Procedure, 1908 এর প্রয়োগ
৯৷ (১) বিশেষ দায়রা আদালতে স্থানান্তরিত মামলা, আপীল ও অন্যান্য আইনগত কার্যধারা নিষ্পত্তির ক্ষেত্রে the Code of Criminal Procedure, 1898 (Act V of 1898) এর বিধানাবলী প্রযোজ্য হইবে৷
(২) বিশেষ জেলা জজ আদালতে স্থানান্তরিত মামলা, আপীল ও অন্যান্য আইনগত কার্যধারা নিষ্পত্তির ক্ষেত্রে the Code of Civil Procedure, 1908 (Act V of 1908) এর বিধানাবলী প্রযোজ্য হইবে৷
