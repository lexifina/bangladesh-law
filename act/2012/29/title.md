# পাবলিক বিশ্ববিদ্যালয় শিক্ষক (অবসর গ্রহণ) (বিশেষ বিধান) আইন, ২০১২
( ২০১২ সনের ২৯ নং আইন )
[ ১০ জুলাই, ২০১২ ]
