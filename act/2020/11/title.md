# আদালত কর্তৃক তথ্য-প্রযুক্তি ব্যবহার আইন, ২০২০
( ২০২০ সনের ১১ নং আইন )
[ ৯ জুলাই, ২০২০ ]
মামলার বিচার (trial), বিচারিক অনুসন্ধান (inquiry), বা দরখাস্ত বা আপিল শুনানি, বা সাক্ষ্য (evidence) গ্রহণ, বা যুক্তিতর্ক (argument) গ্রহণ, বা আদেশ (order) বা রায় (judgement) প্রদানকালে পক্ষগণের ভার্চুয়াল উপস্থিতি নিশ্চিত করিবার উদ্দেশ্যে আদালতকে তথ্য-প্রযুক্তি ব্যবহারের ক্ষমতা প্রদানের নিমিত্ত বিধান প্রণয়নকল্পে প্রণীত আইন
